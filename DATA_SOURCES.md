# Third-party data sources

The public records below provide the participant-level inputs. Use the source repositories' terms when downloading and using their files. The project licences apply to the project's software and aggregate outputs. Local downloads and prepared participant or sample matrices belong under `inputs/`.

The exact retrieval URLs, local filenames and archived SHA-256 digests are declared in [the replay fetcher](tools/fetch_replay_inputs.py) and [the profiles fetcher](tools/fetch_profile_inputs.py). If a provider returns a different representation, use the URL and filename listed for the study and compare the digest against the archived value. Use the provider's original byte stream for CSV/TSV inputs.

PoMet time codes 1, 7 and 8 correspond to baseline, 120 and 180 minutes. The exercise main window is REST/STAT/REC3 and the sensitivity window is REST/REC3/REC22. Profile summaries use joint complete baseline, early and late observations and cluster resampling at the participant level. S3 gives the study-specific times, retention filters and intensity transformations.
